# English Learning UI

Frontend skeleton for SWP391. No backend/database required.

## Requirements
- Node.js 22.x
- npm

## Run
```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Use the DEMO ROLE buttons in the sidebar to switch between User, Manager and Admin.

## Stack
- React 18.3.1
- React Router 6.30.1
- Vite 6.4.1
- @vitejs/plugin-react 4.4.1

`node_modules` and `dist` are ignored by Git.
